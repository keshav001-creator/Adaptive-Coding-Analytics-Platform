<h1 align="center">
  DSA Behavioral Intelligence System
</h1>

<p align="center">
  An AI-powered behavioral intelligence system that tracks DSA problem-solving patterns and generates personalized revision insights using behavioral learning analytics.
</p>

<hr>

<h2>🚀 Features</h2>

<ul>
  <li>Chrome Extension based behavioral tracking</li>
  <li>Active coding time tracking</li>
  <li>Wrong answer detection</li>
  <li>Revision attempt tracking</li>
  <li>MongoDB behavioral history storage</li>
  <li>Learning trend analysis engine</li>
  <li>AI-powered revision intelligence</li>
  <li>Personalized revision recommendations</li>
</ul>

<h2>⚙️ System Workflow</h2>

<h3>1. Behavioral Tracking Layer</h3>

<p>
The Chrome extension continuously tracks:
</p>

<ul>
  <li>Time spent solving DSA problems</li>
  <li>Failed submission attempts</li>
  <li>Revision frequency</li>
  <li>Active browser tab focus</li>
</ul>

<h3>2. Intelligence Processing Layer</h3>

<p>
The backend processes behavioral data to identify:
</p>

<ul>
  <li>Learning improvement trends</li>
  <li>Retention decay patterns</li>
  <li>Consistency in solving behavior</li>
  <li>Revision effectiveness</li>
</ul>

<h3>3. AI Reasoning Layer</h3>

<p>
Behavioral summaries are analyzed using AI to generate:
</p>

<ul>
  <li>Revision priority</li>
  <li>Suggested revision gap</li>
  <li>Personalized learning recommendations</li>
</ul>

<h2>🔍 Low Level Architecture</h2>

<h3>1. Extension Layer</h3>

<ul>
  <li>Tracks active solving duration</li>
  <li>Detects wrong answer submissions</li>
  <li>Monitors question navigation</li>
  <li>Sends behavioral events to backend</li>
</ul>

<h3>2. API Layer</h3>

<ul>
  <li>Receives attempt logs</li>
  <li>Stores revision history</li>
  <li>Triggers intelligence pipeline</li>
</ul>

<h3>3. Intelligence Layer</h3>

<ul>
  <li>Analyzes temporal learning trends</li>
  <li>Detects retention decay</li>
  <li>Generates behavioral summaries</li>
</ul>

<h3>4. AI Reasoning Layer</h3>

<ul>
  <li>Processes behavioral summaries</li>
  <li>Assigns revision priorities</li>
  <li>Generates personalized recommendations</li>
</ul>

<h3>5. Frontend Dashboard Layer</h3>

<ul>
  <li>Displays AI insights</li>
  <li>Shows revision priorities</li>
  <li>Visualizes learning behavior</li>
</ul>
